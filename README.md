# Orkio Core

**Open-source distributed workflow engine for reliable, scalable workflow execution.**

Orkio is a workflow orchestration engine designed to execute long-running, stateful workflows and coordinate distributed jobs.

Define your workflow. Deploy it. Run it. Let Orkio handle state, retries, execution, and coordination.

## ✨ Features

| | Feature | Description |
|---|---|---|
| 🔄 | **Workflow Orchestration** | Build and execute reliable multi-step workflows. |
| ⚡ | **Distributed Execution** | Run workflow jobs across independently scalable workers. |
| 💾 | **Durable State** | Persist workflow state across failures and restarts. |
| 🔁 | **Automatic Retries** | Recover from transient failures with configurable retry policies. |
| ⏱️ | **Long-Running Workflows** | Execute workflows that run for seconds, hours, or days. |
| 📡 | **Event-Driven** | Coordinate execution through asynchronous events and jobs. |
| 📈 | **Horizontal Scaling** | Scale coordinators and workers independently. |
| 🧩 | **Language-Agnostic** | Build workers using the language and stack you prefer. |
| 🔢 | **Versioned Workflows** | Deploy new versions without disrupting running instances. |
| 🛠️ | **Developer-First** | Control and integrate Orkio through CLI, API, and SDKs. |
