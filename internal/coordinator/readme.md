Coordinator появляется тогда, когда после результата Job нужно принимать решение о дальнейшем ходе workflow

Например:

A → B → C

Worker выполняет A:

Worker A
   │
   ├── execute A
   │
   └── TiKV:
       job A = COMPLETED

Само по себе этого недостаточно. Кто решит:

«A завершился → теперь нужно запустить B»?

Вот здесь Coordinator.
